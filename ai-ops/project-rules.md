# Kinjo LLC Website Project Rules

## Editing Rules

- Make small scoped changes
- Preserve mobile responsiveness
- Do not break the contact form
- Avoid unnecessary refactors
- Maintain Kinjo LLC branding
- Protect production stability

## Development Flow

1. Edit code
2. Push to preview branch
3. Verify deployment in Vercel
4. Test site behavior
5. Only then merge to production
