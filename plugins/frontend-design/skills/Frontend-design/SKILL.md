# Frontend Design Skill

## Purpose

This skill helps Claude design and implement high-quality, distinctive frontend interfaces that avoid generic AI-generated aesthetics.

It encourages strong visual direction, thoughtful layout composition, intentional typography, and polished interaction design.

The goal is to produce interfaces that feel professionally designed rather than template-driven.

---

## Core Principles

### Choose a Strong Visual Direction

Before implementing UI, decide on a clear aesthetic direction.

Avoid default frameworks or generic layouts. The design should feel intentional and coherent.

Possible influences include:

- editorial layouts
- modern product interfaces
- technical dashboards
- minimal design systems
- bold typography-led compositions

Pick a direction and apply it consistently.

---

### Avoid Generic AI UI Patterns

Avoid common AI-generated patterns such as:

- excessive gradients
- random colorful blobs
- predictable hero + card grid structures
- overused SaaS dashboard styles
- default Tailwind look without refinement

Interfaces should feel distinctive and intentional.

---

### Typography First

Typography should drive the design.

Consider:

- heading scale
- line length
- rhythm between sections
- font weight contrast
- readable paragraph width

Avoid oversized hero text that dominates the page without hierarchy.

---

### Strong Layout Composition

Layouts should have clear visual structure.

Use:

- intentional whitespace
- asymmetry where appropriate
- strong section separation
- visual rhythm between sections

Avoid flat pages where every section looks identical.

---

### Motion With Purpose

Animation should enhance usability and polish, not distract.

Good motion includes:

- subtle hover transitions
- staggered entrance animations
- gentle section fades
- micro-interactions for buttons and forms

Avoid excessive or flashy animation.

---

### Production-Ready Code

All designs must result in clean, maintainable frontend code.

Follow best practices:

- reusable components
- responsive design
- accessible markup
- performance-conscious implementation

Avoid unnecessary complexity.

---

## Implementation Expectations

When applying this skill:

1. Review the current layout and design system.
2. Identify areas where visual hierarchy can be improved.
3. Refine typography scale and spacing.
4. Improve layout rhythm and section composition.
5. Introduce subtle motion where it improves polish.
6. Ensure responsiveness across mobile, tablet, and desktop.

Focus on **refinement and cohesion**, not unnecessary redesign.

---

## Constraints

Do not change the information architecture unless necessary.

Do not introduce unnecessary design trends.

Maintain usability, accessibility, and professional presentation.

The end result should feel **intentional, refined, and production-grade**.
